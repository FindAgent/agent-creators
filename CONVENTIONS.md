# FindAgent agent creators

This repository builds FindAgent agents. Aider reads this file when started with `--read CONVENTIONS.md` (see `.aider.conf.yml`).

Start from `AGENTS.md`: it lists the playbooks (`playbooks/agents/*.md`), commands (`playbooks/commands/*.md`) and requirements. Read the playbook that matches the request in full and follow it. Never submit or publish for the user.
